# Observations

This directory contains ground-truth annotations and the outputs generated by the pipeline.

## Structure

- `ground_truths/` -- contains original ami annotations (`*_ground_truth.rttm`) used to calculate the diarization error rate (DER).
- `audio_samples/` -- raw audio and video files (e.g. `.wav`, `.mp4`) for testing the pipeline.
- `reports/` -- formal evaluation documents tracking bugs, ablation studies, and hallucination management (e.g., `phase4_analysis.md`).
- `outputs/` -- generated pipeline artifacts:
  - `*_extracted.wav` -- audio extracted from `.mp4` video files.
  - `enhanced_*.wav` -- the cleaned audio.
  - `diarization_*.json` -- pyannote's speaker timestamps.
  - `diarization_*.rttm` -- standard format predictions.
  - `qc_flags_*.json` -- flagged pyannote misattributions based on multi-condition qc.
  - `transcript_*.txt` -- the final smart-transcription texts.
  - `behavioral_metrics_*.json` -- mathematical silence, dominance, and gini centralization metrics.
  - `behavioral_metrics_*.csv` -- flat metrics exported for statistical analysis (SPSS/R).
  - `tagged_transcript_*.json` -- ollama zero-shot nlp tags for psychological safety and sentiment.
  - `tagged_transcript_*.csv` -- flat semantic tags exported for statistical analysis.

## Inspection Instructions
To test the enhancement suite independently:
```bash
Python -m pytest tests/ -v -s
```

To run the full end-to-end pipeline (video extraction + enhancement + diarization + qc + dual-path transcription + phase 4 analytics):
```bash
Python run_pipeline.py -i observations/audio_samples/sample_meeting.mp4 --run-qc --run-analytics
```
